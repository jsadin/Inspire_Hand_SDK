# 新增机型清单

加一台手或一只夹爪，按下面顺序改仓库。目录和 Git 写法见 [开发与Git约定.md](开发与Git约定.md)。给 AI 协作者的完整提示词见 [项目提示词.md](项目提示词.md)。

```
协议(core) → 单测 → 接口包 → 适配器+工厂 → 示例 yaml → README/docs
```

能继承已有帧格式就继承（例如 RH524J1 继承 RH5DG2），只覆写寄存器表和机型特例。

---

## A. 协议（所有新产品必做）

目录：`src/inspire_serial_core/`

1. 新增 `include/<Model>_…protocol.hpp` + `src/<Model>_…protocol.cpp`，实现 `Protocol` 九个虚函数：  
   `getRegisterAddress` / `buildReadCommand` / `buildWriteCommand` / `parseResponse` / `validateChecksum` / `parseTouchData` / `writeRegister` / `readRegister` / `readTouchData`
2. 文件末尾 `REGISTER_PROTOCOL("类型名", 类名)`（SHARED 库自注册）
3. 把 `.cpp` 挂进 `CMakeLists.txt` 的 `add_library(...)`
4. `src/config_loader.cpp` 的 `interfacesProfileFromProtocolType()` 增加前缀匹配，返回机型名（如 `RH524J1`）。**不要**落到默认 RH5DG2
5. `tests/test_<model>_….cpp`：组帧、校验和、解析、错误帧；无触觉则断言 NotSupported。加入 `tests/CMakeLists.txt`

寄存器用驼峰名（`angleSet` / `openLenSet`），与手册一致；新寄存器同时进 `REGISTER_MAP` 和 `REGISTER_READ_LENGTH_MAP`（只写不读除外）。手册与厂商 demo 冲突时以跑通的 demo 为准。

校验和：485 为 `sum(byte[2..n-2]) & 0xFF`；Serial-CAN 为 `sum(ExtId..Meta) & 0xFF`。

`protocol.type` 一般是 `<MODEL>_<bus>`。**例外（已冻结）**：EG-5CD1 写 `EG5CD1`。

---

## B. 接口包

目录：`src/interfaces/<Model>/`

- `package.xml` 的 `<name>` 全小写下划线：`rhxxxx_interfaces` / `egxxxx_interfaces`
- 灵巧手：仿同自由度已有包（6 关节看 RH56H1/F1，13 看 RH5DG2，24 看 RH524J1）
- 夹爪：仿 EG5CD1 / EG2-4C2（`GripperState` + 标量 srv + 可选组合 srv）
- 每个 `.srv` 响应段保留 `string message`，把 `IoError` 说给调用方

---

## C. 适配器（ROS）

目录：`src/driver/`

1. `include/<Model>_interface_adapter.hpp` 继承 `InterfaceAdapter`，实现 `wireTopics` / `wireServices` / `publishRegisterData` / `publishTouchData`
2. `src/interface_adapter_factory.cpp` 增加 `interfaces_profile == "<Model>"` 分支，**不要**掉进默认 `RH5DG2InterfaceAdapter`
3. `CMakeLists.txt`：`find_package`、可执行文件列表、`ament_target_dependencies` 都加上新接口包和适配器 `.cpp`
4. `package.xml` 增加 `<depend>`
5. 组合动作（力控/触控连写）必须走 `ioWriteSequence`，步间间隔在工人线程里 `sleep`（`kCompositeStepMs = 3`），不要在 ROS 回调里抢串口
6. 每条服务/订阅用 `rosIncomingHandIdTargetsThisNode` 校验 `hand_id`（`0` 兼容旧客户端）

---

## D. 配置与启动

只新增示例，**不要**改别人正在用的默认 yaml（除非明确要换仓库默认机型）：

- `src/driver/config/device_protocol_<model>_example.yaml`
- `src/driver/config/ros2_controller_<model>_example.yaml`

`topic.name` 必须是适配器已认识的名字。`devices[].name` 必须等于 launch 的 `--device`。

启动仍用 `inspire_control_single_device.launch.py`，用参数指向示例 yaml：

```bash
ros2 launch inspire_control_ros2 inspire_control_single_device.launch.py \
  device_name:=hand_left \
  device_config:=$(ros2 pkg prefix inspire_control_ros2)/share/inspire_control_ros2/config/device_protocol_<model>_example.yaml \
  controller_config:=$(ros2 pkg prefix inspire_control_ros2)/share/inspire_control_ros2/config/ros2_controller_<model>_example.yaml
```

多设备：一机一口一个 `DeviceWorker`。同 `port` 两台手当前不支持。一份 yaml 只有一个 `protocol.type`。

## E. 文档

- `docs/<机型>协议格式说明.md`（或沿用现有命名，如 `docs/4C2夹爪CAN转Serial通信规则.md`）
- README：结构图、`ROS2 接口说明` 表、该机型全链路/自检各加一节（长文可链到 `docs/`，避免 README 再膨胀）
- 更新本文文末矩阵，以及 [项目提示词.md](项目提示词.md) 的「已支持机型」

## 机型矩阵

| 机型 | protocol.type | 接口包 | 关节/自由度 | 触觉 | 示例 yaml（driver/config） |
|------|---------------|--------|-------------|------|---------------------------|
| RH56F1 | `RH56F1_485` / `RH56F1_canfd` | `rh56f1_interfaces` | 6 | version1 电容 | `device_protocol_rh56f1_example.yaml` |
| RH56H1 | `RH56H1_485` / `RH56H1_canfd` | `rh56h1_interfaces` | 6 | version2 压阻 | `device_protocol_rh56h1_example.yaml`、`device_protocol_rh56h1_canfd_example.yaml` |
| RH56DFX | `RH56DFX_serial_can` | `rh56dfx_interfaces` | 6 | 无硬件（话题保留） | `device_protocol_rh56dfx_example.yaml` |
| RH5DG2 | `RH5DG2_485` / `RH5DG2_canfd` | `rh5dg2_interfaces` | 13 | 有 | `device_protocol_rh5dg2_example.yaml` |
| RH524J1 | `RH524J1_485` | `rh524j1_interfaces` | 24 腱绳 | 无 | `device_protocol_rh524j1_example.yaml` |
| EG-5CD1 | **`EG5CD1`**（不是 `EG5CD1_485`） | `eg5cd1_interfaces` | 夹爪 1 | 20 字节块，接近觉 uint32 | `device_protocol_eg5cd1_example.yaml` |
| EG2-4C2 | `EG2_4C2_serial_can` | `eg2_4c2_interfaces` | 夹爪 1 | 无；仅力控组合 | `device_protocol_eg2_4c2_example.yaml` |

控制器侧配套：`ros2_controller_<model>_example.yaml`（如 `ros2_controller_rh5dg2_example.yaml`、`ros2_controller_rh56f1_example.yaml`）。仓库默认 `ros2_controller_config.yaml` 对应 RH56H1 CAN-FD。
